# W3Schools Python Exercise Agent

Автономный программный агент: открывает выбранные разделы Python Exercises,
читает данные задания, определяет правильный ответ без внешнего ИИ-сервиса,
заполняет форму, проверяет результат и формирует отчёт.

## Что умеет

- работает с выбранными разделами или со всеми разделами из `config.yaml`;
- поддерживает выбор варианта, заполнение пропусков и drag-and-drop задания;
- использует обычное окно Chromium — работу агента видно на защите;
- сохраняет авторизованную сессию локально в `browser-data/`;
- не требует API-ключа, подписки и оплаты;
- не хранит логин и пароль в исходном коде;
- сохраняет отчёт в `reports/` и итоговые скриншоты в `reports/screenshots/`.

## Установка (Windows)

1. Установите Python 3.11 или новее.
2. В папке проекта выполните:

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium
```

3. В `config.yaml` перечислите нужные разделы точно так, как они называются
   на странице Python Exercises.

## Первый вход в аккаунт

```powershell
python -m src.main login
```

Откроется Chromium. Войдите в аккаунт W3Schools самостоятельно, вернитесь в
консоль и нажмите Enter. Сессионные cookies останутся только на этом компьютере.

## Запуск

Сначала безопасный демонстрационный режим без отправки ответов:

```powershell
python -m src.main run --dry-run
```

Полное прохождение:

```powershell
python -m src.main run
```

Если задания ранее были завершены без авторизации и их нужно повторно записать
в аккаунт:

```powershell
python -m src.main login
python -m src.main run --retake-completed
```

Перед обычным запуском агент проверяет, что W3Schools действительно видит
авторизованный аккаунт. Флаг `--retake-completed` открывает повторно только те
разделы, для которых сайт показывает локальное сообщение о завершении.

## Настройка разделов

Пример:

```yaml
sections:
  - Variables
  - Data Types
  - Strings
```

Можно указать и прямую ссылку на первое упражнение раздела.

Чтобы пройти все разделы Python Exercises, которые сейчас показаны на W3Schools:

```yaml
sections:
  - all
```

## Архитектура

1. `W3Navigator` находит выбранные разделы и считывает страницу упражнения.
2. `ProgrammaticSolver` читает правильный вариант или восстанавливает пропуски
   из данных, загруженных самой страницей упражнения.
3. `W3Navigator` вводит ответ и проверяет реакцию сайта.
4. `RunReporter` сохраняет результаты и ошибки в JSON.

## Ограничения

W3Schools может изменить HTML-разметку или внутренний формат заданий. Основные
селекторы собраны в `src/w3_navigator.py`, а логика ответа — в `src/solver.py`.
Если появляется CAPTCHA, агент останавливается: обход CAPTCHA не реализован.
